# Wellness Tracker

A personal daily wellness tracker built as a single HTML file.
No dependencies, no backend required — works entirely in the browser.

## Features

- Daily routine tracking (meditation, posture, cold shower)
- Exercise counters with progress toward goal (push-ups, abs, squats)
- Slider + direct input for logging exercises
- Weekly calendar view
- Streak and completion stats
- Progress chart (7 / 14 / 30 days) per exercise category
- Daily notes
- Optional remote sync via JSONBin
- Info panel with Italian exercise descriptions
- Works offline, saves to localStorage

## Usage

Open `index.html` in any browser. No installation needed.

For cross-device sync, create a free account at [jsonbin.io](https://jsonbin.io),
create a Bin, and enter your Bin ID and Master Key in the sync panel.
